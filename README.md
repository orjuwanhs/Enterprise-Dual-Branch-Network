# Enterprise Dual Branch Network
Designing and developing the network infrastructure for an organization consisting of an HQ and a branch, managing data flow, ensuring security, and encrypting the connection between them across a WAN.

## Description
- Designed and configured a dual-branch corporate network architecture using Cisco Packet Tracer, integrating VLSM subnetting, VLAN segmentation, and Inter-VLAN routing on Multilayer switches.

- Implemented dynamic OSPF routing and secured WAN cross-branch traffic using a Site-to-Site IPsec VPN tunnel.

- Produced comprehensive technical documentation containing addressing schemes, and configuration steps.
